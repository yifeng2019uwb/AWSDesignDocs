# System Design Diagrams

This repository contains system design diagrams created to illustrate technical architecture, data flow, and infrastructure design for various backend features and projects I’ve worked on or studied.

## 🔍 Contents

### 1. **Tag Feature – Access Control System (AWS Internal Project)**
- **Diagram**: `tag-feature-dataflow.drawio.svg`
- **Description**: This diagram illustrates the end-to-end data flow for the tag-based access control system I implemented at AWS. The feature enables clients to associate metadata (tags) with resources, define access rules, and enforce permission checks via backend APIs.
- **Key Components**:
  - Control plane APIs
  - API Gateway
  - Resource State Interface
  - Tag Service
